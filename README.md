## 2. 文本样式

- **粗体文字**：使用双星号 `**粗体**` 或双下划线 `__粗体__`
- *斜体文字*：使用单星号 `*斜体*` 或单下划线 `_斜体_`
- ~~删除线~~：使用双波浪线 `~~删除线~~`
- `行内代码`：使用反引号 `` `行内代码` ``

## 3. 列表

### 无序列表

### 有序列表
1. 第一项

3. 第三项

### 任务列表
- [x] 完成任务一
- [ ] 未完成任务二
- [x] 完成任务三
